# Qur’an Seekho

Responsive static website prototype with English, Hindi, and Urdu interfaces; Urdu right-to-left layout; a learning path; 28 Arabic letters; a pronunciation demo; and a letter-recognition quiz.

## Local use
Open `index.html` in a modern browser. No build step is required.

## Render Static Site
Branch: `main`. Build command: `echo static site`. Publish directory: `.`.

## Religious accuracy and audio
The pronunciation control uses browser text-to-speech for demonstration and is not verified Qur’anic recitation. Before using this for makhraj or tajweed instruction, replace it with properly licensed, qualified-qari-reviewed audio and have religious lessons reviewed by a qualified teacher.
